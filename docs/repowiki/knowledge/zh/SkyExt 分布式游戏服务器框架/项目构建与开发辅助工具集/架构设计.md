本模块是纯工具集合，按职责划分为三类：
- 构建与发布：`dist.py`（Python）通过 `shutil` 扫描源码目录，将 `.so` 直接复制、`.lua` 经 `./bin/luac` 编译为字节码后输出到 `./dist`，再排除 `3rd`、`tools/*/db`、`tools/*/etcd*_data` 等目录并打包为 `skyext.zip`；`dist.sh` 作为入口统一调用。
- 代码生成：`gen_proto.sh` → `proto2spb.lua` 读取 `proto/*.sproto` 并通过 `module.spb` 生成 `build/proto/sproto.spb`；`gen_schema.sh` 借助 `3rd/sproto-orm/tools/sproto2lua.lua` 和 `gen_schema.lua` 生成 `lualib/orm/schema*.lua` 并用 `stylua` 格式化；`gen_roleagent_modules.lua` 扫描 `app/role/roleagent/modules` 下含 `request.lua` 的子目录，模板化生成 `init.lua` 以自动注册角色模块。
- 运行与热更：`run.lua` 作为 Lua 子脚本的统一入口，负责设置 `package.path/cpath`、注入 `_G.SCRIPT_DIRECTORY`、重设 `arg` 表后 `loadfile` 执行目标脚本；`hotfix.sh` + `hotfix.lua` 实现 `refresh` 命令，读取 `hotfix.conf.lua`，合并 `update_files` 与 `code_files` 内容并通过系统 `md5sum`/`md5` 计算 checksum，回写配置文件中的 `time` 与 `checksum` 字段。
- 开发环境：`etcd/` 与 `mongodb/` 子目录各含 `docker-compose.yml` 与 `start.sh`，用于拉起本地依赖服务。
依赖方向单向：shell 脚本仅调用 `run.lua` 或外部命令，Lua 工具依赖项目自身的 `lualib`、`skynet/luaclib`、`3rd/sproto-orm` 等第三方库，不反向依赖业务代码。

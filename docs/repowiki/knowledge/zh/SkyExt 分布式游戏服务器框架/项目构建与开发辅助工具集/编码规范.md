- Shell 入口脚本统一采用 `cd "$(dirname "$0")/.."` 切换到仓库根目录后再调用 `./bin/lua tools/run.lua ...` 执行 Lua 工具，保证路径相对性一致。
- Lua 工具脚本通过 `run.lua` 统一加载，由 `run.lua` 负责拼接 `package.path`/`package.cpath`、设置 `_G.SCRIPT_DIRECTORY` 并重新构造 `arg` 表，使被调脚本可感知自身位置与参数。
- 代码生成类 Lua 脚本（如 `gen_roleagent_modules.lua`、`proto2spb.lua`）通过遍历 `arg` 接收输入文件列表，并将生成结果写入固定输出路径（如 `app/.../init.lua`、`build/proto/sproto.spb`）。
- 对外部命令的调用采用 `io.popen` 或 `subprocess.run` 并以 fallback 方式兼容多平台（如 `hotfix.lua` 同时尝试 `md5sum` 与 `md5`，`dist.py` 检测 luac 是否已编译）。

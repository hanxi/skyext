- 每个子模块通过 `init.lua` 暴露统一入口，顶层文件直接返回模块表 `M`，由 `require` 消费。
- 对外 API 统一以 `local M = {}` 定义并 `return M`，方法通过 `M.xxx = function(...)` 挂载。
- 日志统一走 `require "log"` 提供的 `info/debug/warn/error`，错误路径使用 `assert` 或 `sys_error` 而非裸 `error`。
- ORM 文档通过元表拦截 `__newindex` 记录脏键，并以 `__dirty`/`__all_dirty` 两级标记实现增量提交到 MongoDB。
- 需要全局钩子的功能（如 ORM 对 `next/table.*` 的支持）集中在 `skyext.lua` 中一次性 patch，避免分散修改。
- C 扩展模块遵循 `LUAMOD_API int luaopen_xxx(lua_State*)` 命名规范，并在 `luaopen_*` 中完成第三方库初始化（如 `sodium_init()`）。

- 每个子目录（account、role、robot）对应一个独立的 Skynet 进程，由 etc/app/*.app.lua 中的 service 列表声明加载，etc/*.conf.lua 提供进程级配置（端口、数据库、etcd 节点等），common.app.lua 集中定义跨进程共享的环境路径与服务加载规则。
- 进程间通信统一基于 sproto 协议（经 tools/gen_proto.sh 生成）与 etcd 服务发现：角色服务通过 roleagentmgr 管理多实例角色并暴露 roleagent_api；机器人服务以 HTTP 调用账户服务、再以 sproto 连接网关节点模拟玩家；账户服务则协调用户/角色数据与游戏服节点。
- 构建与部署由根 Makefile 统一管理：make build 编译 skynet 与 C 扩展（jchash/cjson/traceback/lfs/crypto），make proto/schema/autocode 生成协议、ORM schema 与角色模块代码，make dist 打包发布，所有子进程共享同一份 lualib、luaclib 与 proto 产物。
- 监控节点（monitor.app.conf）作为可插拔组件接入同一集群，用于观测各服务状态。

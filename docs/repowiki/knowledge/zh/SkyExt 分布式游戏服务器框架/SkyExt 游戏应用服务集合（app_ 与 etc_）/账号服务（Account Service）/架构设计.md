模块以 `app/account/main.lua` 为 Skynet 进程入口，启动时加载 `config`、`launcher`、`log`，调用 `http_server.start` 暴露 HTTP 端口并通过 `http_server.register_router("account_router")` 挂载路由；路由逻辑集中在 `app/account/lualib/account_router.lua`，按 HTTP 方法组织为 `GET`/`POST` 表，当前实现 `/roles` 与 `/create_role` 两个端点。服务依赖外部库：`jwt` 校验登录令牌、`user_db_api`/`role_db_api` 读写用户与角色数据、`id_generator` 生成角色 ID、`rolenode_api.calc_rolenode` 计算角色所在游戏服节点、`errcode` 统一错误码、`time.now_ms` 记录创建时间。配置采用多实例模式：`etc/account1.conf.lua` 与 `etc/account2.conf.lua` 分别指定不同的 `app_config_path`（`account1.app.lua` / `account2.app.lua`），两份 app 配置仅差异端口号（8080/8081、9090/9091）与 snowflake machine id（2/3），均 `include "common.app.lua"` 复用公共配置，从而支持横向扩展多个账号服务实例。

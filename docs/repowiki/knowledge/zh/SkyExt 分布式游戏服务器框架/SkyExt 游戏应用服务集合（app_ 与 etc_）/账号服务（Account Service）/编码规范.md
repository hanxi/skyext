- HTTP 路由以模块表形式导出，键为 `METHOD["path"]`（如 `GET["/roles"]`、`POST["/create_role"]`），由 `http_server.register_router` 动态注册。
- 所有需要鉴权的接口统一在入口处解析请求参数后调用 `jwt.verify(token, login_jwt_secret)`，失败时返回 `errcode.TOKEN_ERROR`。
- 业务错误通过 `errcode` 模块中的常量（如 `SERVER_NOT_EXIST`、`ROLE_TOO_MANY`、`DB_ERROR`）统一编码响应体 `{ code = ... }`。
- 配置项通过 `config.get` / `config.get_number` / `config.get_table` 读取，并提供默认值（如 `max_role_count or 5`、`port or 8080`）。
- 多实例部署通过复制 `etc/app/accountN.app.lua` 与 `etc/accountN.conf.lua` 并修改端口与 snowflake machine id 完成，核心代码零配置改动。

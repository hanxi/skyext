- 配置项以顶层 Lua table 或全局变量形式暴露，如 `etcd_config`、`mongo_config`、`log_level` 等，供各服务按需读取。
- 可覆盖的配置使用 `x = x or { default }` 模式（如 `log_config`），便于在子应用配置中局部覆盖默认值。
- 数据库连接采用 `center`/`role` 等多实例结构，每个实例统一包含 `connections`、`cfg`、`collections` 三段式配置。
- 子应用配置通过 `include "common.app.lua"` 复用公共配置，再追加自身特有字段（如 monitor 的 `cluster_*`）。

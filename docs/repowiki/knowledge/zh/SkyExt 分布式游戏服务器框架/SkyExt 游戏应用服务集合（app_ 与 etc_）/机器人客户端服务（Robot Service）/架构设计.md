模块由两个入口组成：`etc/robot.conf.lua` 指定应用配置路径 `etc/app/robot.app.lua` 及启动脚本 `start = "robot"`；`app/robot/main.lua` 作为进程入口，按需加载 console 服务并按 `robot_count` 并发创建多个 `robot/robotagent` 子服务，每个子服务通过 `skynet.call(..., "start", {id, name})` 初始化。

`app/robot/robotagent/main.lua` 是单个机器人 Agent 的实现：启动时生成 JWT 令牌调用 `account_host` 的 `/roles` 接口获取或创建角色，再根据返回的 `rolenode` 从 `gate_nodes` 配置表解析网关 IP/端口，使用 `skynet.socket` 建立 TCP 连接；随后通过 `sproto_api.call` 发送 `login.login`、`role.login_info` 等登录流程消息。接收侧在独立 fork 协程中循环读取 socket 数据，按自定义长度前缀（2 字节网络序包长 + 包体）分包后交由 `sproto_api.raw_dispatch` 分发响应。依赖方向单向：main → robotagent → sproto_api/httpc/jwt/socket，不反向引用上层。

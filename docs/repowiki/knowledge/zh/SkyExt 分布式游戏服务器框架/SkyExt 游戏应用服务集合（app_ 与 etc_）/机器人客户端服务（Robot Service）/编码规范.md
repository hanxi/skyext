- 服务入口统一通过 `skynet.start(function() ... end)` 注册，并使用 `cmd_api.dispatch(CMD)` 暴露 `CMD.start` 等命令供父服务调用。
- 配置集中放在 `etc/app/robot.app.lua`，运行时通过 `config.get` / `config.get_number` / `config.get_table` 三类方法分别读取标量、数字和表类型配置。
- 对外部 HTTP 调用的返回值统一检查 `status == 200` 且 `res.code == errcode.OK` 后才继续后续逻辑，失败路径通过 `log.error` 记录并提前返回。
- 日志输出统一使用 `log.info` / `log.error` / `log.debug` 并以键值对形式传递上下文字段（如 `id`、`status`、`err`）。

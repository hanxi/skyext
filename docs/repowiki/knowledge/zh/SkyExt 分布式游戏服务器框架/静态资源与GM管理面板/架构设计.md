模块由两类静态资源组成：res/ 目录存放服务端可读取的 Lua 数据表，其中 hero.lua 以数字键映射英雄基础属性（Height、Sex、Name、MountId），res/lazy/param.lua 集中定义 HitCorrection、NameLimit、InitItem、InitMission 等运行时可调参数；public/gm.html 是一个自包含的单页 HTML，内嵌 CSS 与 JavaScript，通过 fetch 调用后端 /gm/list 与 /gm/execute 接口动态拉取命令元数据并渲染左侧命令列表、右侧参数表单及结果表格，支持搜索过滤、移动端侧边栏折叠与响应式布局。依赖方向单向：浏览器前端 → 后端 GM 服务 API，Lua 资源由服务端在启动或热更时加载。

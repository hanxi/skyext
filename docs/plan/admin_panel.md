# 管理后台

## 实现计划

采用前后端分离的后台开发模式，后端不一定会采用 skynet 实现。后台的后端与 skynet 游戏节点之间采用 GM 指令的方式交互（不像 [skynet-admin](https://github.com/hanxi/skynet-admin) 是通过 cluster 的）。需要支持多用户登录和用户权限管理，比如某些用户只能查询信息。

游戏节点的发现使用 etcd 来实现，游戏节点启动时向 etcd 注册自己的 GM Web 服务的 IP 和端口。后台通过 etcd 发现游戏节点，并使用 GM 指令与游戏节点交互。

## 功能模块

### 1. 玩家管理

- **账号管理**：查询（ID、昵称、手机号）、封禁/解封、数据查看（等级、VIP、资产）、登录日志、设备信息
- **角色管理**：信息查询、数据修改（等级、经验、属性）、删除/恢复、转区

### 2. 游戏数据管理

- **道具/物品管理**：背包查询、道具发放/回收、装备管理、货币管理
- **游戏进度管理**：关卡进度、任务完成情况、成就数据、副本记录

### 3. 运营活动

- **活动配置**：创建/编辑/删除、时间设置、奖励配置、开关控制
- **公告管理**：游戏公告、维护公告、弹窗公告、跑马灯消息

### 4. 邮件系统

- **邮件发送**：全服邮件、指定玩家邮件、条件筛选邮件、补偿邮件
- **邮件管理**：邮件模板、发送记录查询、邮件撤回

### 5. 充值/支付管理

- **订单管理**：充值订单查询、补单、退款、支付渠道统计
- **商品管理**：商品上下架、价格配置、礼包管理、首充/限购设置

### 6. 游戏配置

- **基础配置**：服务器列表管理、版本控制、白名单/黑名单、开服时间
- **游戏参数**：经验倍率、掉落倍率、功能开关、敏感词过滤

### 7. 数据统计分析

- **运营数据**：DAU/MAU 统计、在线人数实时监控、留存率分析、付费率统计
- **经济数据**：货币产出/消耗、道具流通统计、交易行情分析、经济平衡监控

### 8. 客服支持

- **工单系统**：玩家申诉处理、问题分类管理、工单流转、处理记录
- **聊天监控**：聊天记录查询、违规内容监控、禁言管理

### 9. 系统管理

- **权限管理**：管理员账号管理、角色权限配置、操作日志审计、敏感操作二次确认
- **服务器管理**：服务器状态监控、热更新管理、数据库备份、紧急维护
